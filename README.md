# DraftClock

DraftClock is an iOS/iPadOS application designed to provdie a simple, customizable draft timer for fantasy sports and other draft-style events.

The application is designed primarily for iPad while remaining fully functional on iPhone.

## Planned Features

- Configurable number of teams and rounds
- Snake and linear draft formats
- Customizable pick timers
- Different timer durations based on round
- Team names and draft order configuration
- Start, pause, reset, previous pick, and next pick controls
- Automatic round and pick tracking
- Saved draft configurations
- Audible and haptic timer alerts

## Future Ideas

- AppleTV companion display
- External display / AirPlay support
- Draft history
- Additional customization and display options

## Platform

- iOS / iPadOS
- Swift
- SwiftUI
- Xcode

## Development

DraftClock is currently under active development.

The initial development focus is an iPad-first interface with responsive support for iPhone.  Core draft and timer logic will be kept separate from presentation where practical to support future platforms such as tvOS.
